# Chrome Web Store listing — Tab Suspender

## Name
Tab Suspender

## Summary (max 132 chars)
Manually suspend tabs to free up memory without closing them. One click, no tracking, no settings to learn.

## Description
Tab Suspender gives you a simple, manual way to reclaim memory from tabs you're not using — without losing them.

Open the popup to see every tab in the current window, then:

• Suspend any single tab with one click
• "Suspend Others" — keep the tab you're on, suspend everything else
• "Reload All" — bring every suspended tab back instantly
• Click any tab in the list to jump straight to it

Suspended tabs stay exactly where they are in your tab strip. Their title and icon remain visible, and they reload the moment you click them.

Tab Suspender is deliberately minimal:

• Fully manual — nothing is suspended unless you say so
• Pinned tabs, tabs playing audio, and your active tab are never touched
• No background processes, no timers, no bloat
• No data collection of any kind — the extension never leaves your browser

Uses Chrome's native tab discarding, the same mechanism Chrome itself uses under memory pressure.

## Privacy tab answers
- **Single purpose description:** Lets the user manually suspend (discard) browser tabs to free up memory, and reload them on demand.
- **Permission justification — `tabs`:** Required to list the tabs in the current window (title, URL, favicon shown in the popup), to discard tabs the user chooses to suspend, and to reload or focus tabs the user clicks. Tab data is only displayed in the popup; it is never stored or transmitted.
- **Remote code:** No
- **Data usage:** Does not collect or transmit any user data.
